# Реестр договоров

Одностраничное приложение (`index.html`) для учёта договоров. Сервер и установка не нужны — откройте файл в браузере.

## Возможности

- Таблица договоров: номер, дата, клиент, ИНН, предмет, сумма, срок действия, статус, ответственный.
- Поиск по номеру, клиенту, ИНН, предмету, ответственному и примечанию (с подсветкой совпадений).
- Фильтры по статусу и периоду даты договора; сортировка по любой колонке (клик по заголовку).
- Статус считается автоматически: «Действует», «Истекает» (осталось ≤ 30 дней), «Истёк»; вручную можно указать «Черновик», «Исполнен», «Расторгнут».
- Сводка: количество договоров, общая сумма, сколько действуют / истекают / истекли.
- Добавление, редактирование (клик по строке) и удаление договоров; предупреждение о дублирующемся номере.
- Экспорт в CSV (открывается в Excel), импорт CSV/JSON, резервная копия в JSON.

## Хранение данных

Данные хранятся в `localStorage` браузера — только на этом компьютере и в этом браузере.
Регулярно делайте резервную копию (кнопка «Резервная копия (JSON)»), а для переноса на другой компьютер используйте импорт.

## Формат CSV для импорта

Разделитель `;` или `,`, первая строка — заголовки, колонки по порядку:

```
№ договора;Дата;Клиент;ИНН;Предмет;Сумма;Действует до;Состояние;Ответственный;Примечание
2026/15;01.10.2026;ООО Ромашка;7701234567;Поставка оборудования;150000,00;31.12.2026;Подписан;Петров;
```

Даты — `ДД.ММ.ГГГГ` или `ГГГГ-ММ-ДД`. Состояние — `Подписан`, `Черновик`, `Исполнен` или `Расторгнут`.
